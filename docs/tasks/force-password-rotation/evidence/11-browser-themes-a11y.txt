## Keyboard traversal

`browser.press` did not move focus (every Tab press left `document.activeElement`
on `BODY`), because the browser host had no visible desktop window, the same
constraint that blocked screenshots. Keyboard order was therefore not exercised
end to end. The form uses native `<input>` elements in DOM order, visible labels
and a native submit button; focus styling is verified above.
